# Cesanta

> Cesanta develops embedded networking and IoT software. Its flagship is the Mongoose
> embedded web server / networking library (HTTP, WebSocket, MQTT, TCP/IP) deployed in
> 100M+ devices, alongside Mongoose OS (an IoT firmware framework) and mDash, a managed
> IoT cloud platform offering device management, OTA updates, a device database, and a
> REST API.

## APIs

- [mDash REST API v2](https://mongoose-os.com/docs/mdash/api.md): Device management, OTA, RPC, data, keys, and notification logs. Bearer-token auth. Base URL https://dash.mongoose-os.com/api/v2

## Specs

- [mDash OpenAPI](openapi/cesanta-mdash-openapi.yml): OpenAPI 3.0 captured from the published mDash REST API reference.
